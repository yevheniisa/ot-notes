# OT Glossary

| Term | Meaning |
|---|---|
| HMI | Human-Machine Interface. Operator screen to see *and control* the process through a PLC/DCS. |
| PLC | Programmable Logic Controller. Runs control logic and drives field devices. |
| DCS | Distributed Control System. Plant-wide control system, common in oil & gas and refining. |
| SIS | Safety Instrumented System. Independent layer that trips the process to a safe state when limits are crossed. |
| Setpoint | Target value the controller holds (e.g. tank level 60%). |
| Loss of view / manipulation of view | Operator can't see the process / sees false values. |
| DMZ (OT) | Buffer network between business IT and the control network. Nothing talks straight through it. |
| Jump host | Hardened server in the DMZ that remote users connect to first; sessions are logged and controlled. |
| MOC | Management of Change. Formal approval before changing the process, setpoints or logic. |
| Historian | Database that stores process values over time; trends are read from it. |
